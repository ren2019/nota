# Triage labels

技能提到的五个分诊角色采用默认标签名：

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估。 |
| `needs-info` | `needs-info` | 等待报告者补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 规格已充分明确，可交给 agent 实施。 |
| `ready-for-human` | `ready-for-human` | 需要人工实施。 |
| `wontfix` | `wontfix` | 不处理。 |

当技能要求添加、移除或筛选某个分诊角色时，使用本表的 GitHub 标签。以后如需改名，更新此映射并同步 tracker 中的标签。
