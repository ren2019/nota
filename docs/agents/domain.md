# Domain docs

本项目采用 **single-context**：根目录 `GLOSSARY.md`，架构决定在 `docs/adr/`。

## 读取规则

- 探索代码前，如存在根目录 `GLOSSARY.md`，先读取，输出沿用其中的领域术语。
- 读取 `docs/adr/` 中与当前工作相关的决定；如方案与既有 ADR 冲突，明确说明冲突与重新讨论的原因。
- 文档尚不存在时正常继续；术语或架构决定实际明确后，再由领域建模工作按需建立，避免预建空文档。
- 将来若存在根目录 `GLOSSARY-MAP.md`，先读取映射，再读取当前工作涉及的上下文词汇表及相关 ADR。

## 布局

- `GLOSSARY.md`：项目共用领域词汇。
- `docs/adr/`：项目架构决定记录。
- 当前不拆分多个上下文，也不建立按上下文划分的词汇表或 ADR 目录。
