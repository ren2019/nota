## 验收边界与重跑

`npm run test:journeys` 启动独立本地 Vite 服务和临时目录中的真实 HTTP 曲谱库，使用 Playwright Chromium 操作正式 App 的可见入口、CodeMirror、实际排版和实际本地 OMR。最终断言取自同一 App 当前文档、公开曲谱库 API 与下载文件。没有替换编辑器、转换或识别引擎。

保存故障在 HTTP 边界注入，409/404 用临时库的真实并发更新和删除产生；联网来源采用固定 HTTP 返回，以隔离外部网络。它们验证客户端旅程，不证明线上馆藏新增或外部服务可用。文件选择的空结果通过浏览器文件输入注入，不能当成 iPhone 原生相册取消操作通过。

- 命令：`npm run test:journeys`。默认监听隔离端口，端口占用时拒绝启动；不访问已部署服务。临时库结束即删除。
- 证据：忽略的 `local/qa/spec9-journeys/`，包含逐旅程截图、`report.json`、真实图片输入和识别观察。原图、曲谱正文、下载成品不随 Git 上传。
- 定向调试可设 `NOTA_JOURNEY_FILTER` 为场景名片段；定向通过不能代替整套通过。
- 原专业功能可用 `npm run test:editor` 重跑；其可选私有项目输入与限制见对应脚本及 Dolce 对照记录。

| 旅程 | 通过的可观察结果 |
| --- | --- |
| 首页空库 / 加载故障 | 无预置曲目；错误可见，刷新后进入真实空库，计数为零。 |
| 保存 503 / 重试 | 具体失败可见；留在编辑，正文和 dirty 不变，库未改变；重试更新原 id，成功才回练习。 |
| 慢保存后继续改谱 | 正在提交的旧文本落库；UI 保留后续真实 CodeMirror 修改并保持未保存，再次保存才确认新版本。 |
| 真实修订冲突 | 取消另存时保留本机正文、远端更新和编辑态；明确另存副本后产生新 id，双方版本均保留。 |
| 替换保护 | 取消不换稿；保存失败不继续新建；保存后继续先提交旧稿再新建；放弃后继续才用体验稿替换。 |
| 自动草稿恢复 | 等待实际自动保存后重载，恢复提示使用真实库名；恢复原修改、dirty 和库 id，保存更新原记录。 |
| 重命名 | 取消 / 故障 / 409 不伪装成功；成功只改库名，未保存的正文仍留当前稿，已提交正文没有被管理动作写回。 |
| 删除 | 取消 / 故障 / 409 保留记录；确认且服务端成功才回库，列表和计数减少；后退 / 重载不复活条目或恢复已删稿。 |
| 管理 404 | 远端已删记录后重命名 / 删除显示可恢复错误，当前正文保留，不偷偷重建记录。 |
| 调式与人工编辑 | 两种转换确实改动同一正文；可还原到转换前；再手改音符后旧还原禁用，不覆盖人工修改。 |
| 查谱异步与采纳 | 未搜索空态；返回保查询和选择；过时搜索 / 准备响应不恢复旧候选；校验失败禁用采纳；采纳取消保当前稿和搜索，明确放弃后才采纳，未保存不入库。 |
| 乐谱文件输入 | 文件选择空结果、非乐谱文本失败保旧稿；随后真实 `.123` 输入进入未入库编辑稿，旧库记录未变。 |
| 新图片设置 / 错误 | 选图后显示类型和真实页数范围；设置取消、坏图解码失败保旧正文，错误和重新选图可达；无附属项目时不误报当前稿含原图。 |
| 新图识别 / 校正 / 往返 | 从实际 App 下载的 PNG 页经真实本地模型识别，实际非空识别文本先入库并重开一致；再经 CodeMirror 人工校正、更新同 id、重开一致；原图字节摘要不变。后续坏图替换失败仍保原项目与原图字节。 |
| 详情页拖图失败 | 在真实详情页注入文件拖放，错误弹窗可见；重新选择图片打开浏览器选择入口，空选择仍保留同一首稿件。 |

## 本轮发现并修复

每项先用上述真实 App 旅程复现失败，再最小修复并复跑：

1. 详情页隐藏专业状态栏，保存失败仅写该栏，用户看不到原因。改为用原有对话框显示具体保存错误；失败仍保留编辑和替换保护，关闭后可重试。
2. OMR 的 `hasInputs` 按上游设计包含失败待重试输入。详情原图身份提示改为检查当前附属识别项目，不把失败输入说成当前稿已附带原图；没有删除原引擎保留失败输入供重试的语义。
3. 详情页拖入图片识别失败同样只写隐藏的专业状态栏。非首页失败用原有模态显示具体错误和重新选图入口；首页保持原错误和重试，不增加全局消息系统。
4. 简谱识别返回零音符时仍 emit 空头并替换旧稿。落地前检查实际识别结果含音符（含休止符），无内容走已有事务回滚并提供双语错误。没有调整 OCR 几何、模型或音符判定算法。

## 仍需真实设备

用户已明确确认 iPhone 经 Safari 添加到主屏幕、从图标独立启动并打开曲谱成功；重新打开保持登录亦已确认。该结论保留，不重复列成未验，也不补造设备型号或系统版本。

以下系统行为仍需实际设备记录，不能由 Chromium 窗口或文件输入注入代替：

- iPhone Safari 与独立 PWA：中文软键盘下查谱 / 命名与按钮可达；拍照、相册 / 文件选择与取消；横竖屏安全区。
- iPhone：人耳音高 / 节奏、调速循环与系统音频中断 / 后台切回；真实 PDF / PNG / ZIP 接收、分享与打印。
- iPhone：网络失败后的保存 / 恢复和返回组合；当前桌面脚本提供客户端回归证据，未验证该设备的存储 / 系统行为。
- Android 浏览器 / PWA：缺设备，输入、音频、后台、接收与返回仍待验。

因此 #19 与父 #9 的真机验收边界仍开放；不得因本轮自动复验通过就批量勾选或关闭全部标准。
