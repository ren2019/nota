### 正式入口冒烟

- 通过正式 HTTPS 入口实际操作统一登录页；勾选记住登录后取得持久会话，新的 WebKit 浏览器上下文沿用该会话可直接进入。未登录曲谱库 API 仍返回 401，Manifest 保持 standalone。
- 正式页面 HTML 和入口 JS / CSS 与本次构建逐字节一致；保留原 LaunchAgent 配置，静态产物与原曲谱库均有发布前备份及可回退副本。
- 实际文件导入 → Dolce 源码改音 → 返回同一稿件 → 两种调式 → 保存入库 → 刷新重开正文一致 → 播放进度推进 / 暂停 → PDF / 图片下载均通过。下载检查文件签名、非空内容并保存本地证据。
- 临时测试谱的重命名和确认删除通过；中文“贝多芬”的真实联网搜索及下载准备候选通过，没有使用受控返回代替生产来源。
- WebKit 手机参数检查横竖屏练习 / 编辑底栏，正式入口实际底部基础留白为 16px，无全页横向溢出。它不增加真实 iPhone 系统安全区验收的结论。
- 冒烟只新增专用临时测试谱，结束后通过 UI 删除；原有曲谱文件 SHA-256 完全不变，记录数恢复，服务配置未变化。完整报告、截图、产物与备份仅保存在忽略的 `local/runtime/`，不上传真实内容或会话 Cookie。

该轮收口时公开 tracker 开放任务为零。后续文档提交不改变上述已部署功能版本；不把尚无真机证据的系统行为写成通过。

### 自动化验收边界

用户最新要求“这些你用浏览器自动化自己测”，本轮依该范围收口，不再安排用户逐项手工操作。浏览器手机参数与触控验证不等于真实 iOS 系统软键盘、相册 / Files、分享打印、锁屏 / 来电 / 系统杀进程；这些没有新增实机证据。headless WebKit 切页时保持可见，文档明确只证明切页后保稿和播放器可操作，没有伪造系统隐藏事件。Android 无真机证据。

此前已确认的 iPhone 主屏幕安装、独立启动、打开曲谱和重新打开保持登录继续有效。真实照片整谱自动识别准确性仍未通过，人工校正不算自动识别成功；不承诺离线曲谱库或后台连续播放。

最终关票状态以 tracker 为准；没有把上述系统边界补写为通过，也不沿用等待用户手工逐项验收的旧阻塞条件。
