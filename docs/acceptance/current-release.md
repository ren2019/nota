## 自动化验收边界

用户最新要求“这些你用浏览器自动化自己测”，本轮依该范围收口，不再安排用户逐项手工操作。浏览器手机参数与触控验证不等于真实 iOS 系统软键盘、相册 / Files、分享打印、锁屏 / 来电 / 系统杀进程；这些没有新增实机证据。headless WebKit 切页时保持可见，文档明确只证明切页后保稿和播放器可操作，没有伪造系统隐藏事件。Android 无真机证据。

此前已确认的 iPhone 主屏幕安装、独立启动、打开曲谱和重新打开保持登录继续有效。真实照片整谱自动识别准确性仍未通过，人工校正不算自动识别成功；不承诺离线曲谱库或后台连续播放。

最终关票状态以 tracker 为准；没有把上述系统边界补写为通过，也不沿用等待用户手工逐项验收的旧阻塞条件。
