# Agent 曲谱库维护验收

规格与任务以 [#23](https://github.com/ren2019/nota/issues/23) 及其子任务为准。本文记录 2026-10-28 的验证范围，不另维护任务状态。安装与协作见 [工具说明](../agent-tools.md)，接口和支持条件见 [CLI 说明](../../cli/README.md)。

## 交付与安装

- Node.js 24.22.1、npm 10.9.9；CLI `0.1.0`、Codex CLI `0.162.1`、SkillFlow `1.5.9`。
- 实际生成交付压缩包，在仓库之外解包并 npm 安装 CLI；工具、私有配置及 SkillFlow 导入来源都位于长期目录，可独立于开发工作树使用。
- SkillFlow 先 list/preview，再正式 import 并部署到 Codex，inspect 显示 ACTIVE。安装前后其他来源的完整摘要一致；doctor 仅有安装前已存在的无关提示。
- 新开的 Codex 会话只收到 `$nota-library` 名称与原始输入文件，实际从 SkillFlow 管理的已部署来源读取命令参考，并调用已安装 CLI。未通过手工复制目标 skill 或改写管理状态完成安装。

## 真实样谱与协作

选用《Five Little Ducks》的 “Five little ducks went swimming one day” 版本，D 大调、4/4、八小节、34 音。版本、来源、许可、逐音转写依据、原图与全部实际数据保存在忽略目录 `local/`；原图定位是人工校对映射，不是自动识谱准确性验收。

八个独立 Codex 场景通过：

| 场景 | 实际结果 |
| --- | --- |
| 明确新建 | 查重、服务端检查、新建及回读；直接保存，返回链接和检查范围 |
| 明确普通修改 | 指定首音改动、保存回读，再按明确要求恢复原谱；其余内容保留 |
| 新增同名 | 找到已有曲谱后，先问修改已有谱还是另建版本，尚未写入 |
| 多个候选 | 列出两个编号、更新时间与来源后请求选择，尚未写入 |
| 音乐歧义 | 不能从未提供的哼唱确定音高，询问具体音名/八度，尚未写入 |
| 并发冲突 | 真实另一维护者在读取后更新；agent 报告版本冲突、保留提案并停止写入 |
| 新建结果未确认 | 真实服务已写入，传输丢失响应且无法回读；agent 仅查证，报告未知，不重复新建 |
| 实际实例完整原图维护 | HTTPS 新建、位置移动与首音临时八度修改、软删、恢复、还原原文及逐步回读 |

并发与响应丢失仅在传输边界受控注入，实际解析器、服务与文件持久化均未 mock。未知结果场景中实际新建 POST 仅一次，真实库中也只有一份对应记录。

## 实例与网页

真实 HTTPS 入口验证有效、缺失、错误及撤销的凭据；撤销一人后另一人继续可用。机器凭据不能登录网页或访问普通网页 API，相似前缀、编码和点段没有穿透原有保护。首次新增服务/网关能力后，同一服务进程内完成加曲、改曲、删除和恢复，未为这些内容变动重新发布或重启。

同一真实实例的本机 HTTP 网页已实际打开谱面，核对 34 音/八小节；加上含 emoji 的源码前缀后和还原后，首音、中段、低音与末音共八次原图点选均正确定位。真实播放进入 playing 且进度推进，截图已目视核对。HTTPS CLI 与访问保护已测；本轮网页操作使用本机同实例入口，没有将其表述为已完成 HTTPS 网页登录验收。

另做有意服务重启：软删记录重启后仍可发现，恢复沿用同一身份，正文、来源、原图项目、版式等完整记录保留。既有 14 份曲谱的文件 SHA-256 均未变化。最终保留一份正确、可试听的本次主谱；所有真实地址、编号、凭据、回执、Codex 日志与截图保存在私有 `local/agent-library-acceptance/`。

## 回归与边界

- `npm test`：816 个转换用例、27 条真实 HTTP/独立安装测试，以及文档会话、输入与播放检查通过。
- `npm run build` 通过；原图同步合并后的完整网页旅程 22/22，通过实际浏览器与目视核对。
- 交付包测试实际解包、安装并连接真实服务；skill 语法检查通过。语法检查或静态文本检查不代替上述 Codex 行为验收。

最终审查追加验证来源身份变化：已对照曲谱仅更名或澄清许可时保留结论；替换 URL、文件指纹、声部、选取范围、对照方法或导入谱文指纹后，旧结论变为 `source-unverified`，正文、许可及版式保留。独立安装 CLI 与直接网页 HTTP 更新均通过，网页刷新后显示未验证原稿。服务器与 CLI 共用归一化规则，回读仍严格比较完整来源对象。

当前远程音乐改动对照限单首、单声部单旋律；原图谱文修改限完整映射的 `123/jianpu` 项目。其他不安全输入明确拒绝，保留原件。没有新增 MCP、账号角色、修改历史、永久删除或自动识谱服务。

服务端解析、结构与改动核对通过，并不等于已经独立核对可信原稿或由人试听。人的最终试听仍可在曲谱库进行，不作为 agent 保存或本轮完成的硬 gate。

## 2026-10-29 歌词标准与样谱补全

用户确认此前样谱试听通过，并追加入库标准：默认必须有歌词，只有用户明确同意该曲谱无歌词时例外。已写入 skill，并通过 SkillFlow 定向更新本机 Codex 安装；交付包同步刷新，技能格式校验与安装文件比对通过。

原样谱按所选原图补入完整第一段歌词，34 个音节对应现有八小节的 34 个音符。独立 CLI 经 HTTPS 检查、按版本更新并回读通过；报告确认音高、节奏、连线与曲式不变。网页实际打开并逐音节核对解析结果、目视核对歌词排版；原图四处点选仍准确，源图及其他未改项目条目逐字节保留。此次未扩展到后续段落，未将此前旋律试听表述为补词后的再次人工试听。私有证据位于 `local/agent-library-acceptance/lyrics/`。
