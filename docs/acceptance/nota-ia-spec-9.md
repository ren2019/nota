## 最终整合旅程

逐项记录通过的版本、窗口/设备、曲谱、操作和实际观察；按钮出现、颜色改变或源码入口存在均不单独当作功能通过。

1. 首次进入：紧凑 L1 品牌/中英 slogan/体验/GitHub；图片、文件、查谱与新建入口；没有原型变体栏、Logo 方案选择或固定演示曲库。
2. 输入：体验、空白、文件、图片及在线候选分别带入真实当前稿。取消文件/相册不覆盖旧稿；图片先选择后设置；如实说明实际处理页数，不承诺新增多页识别引擎。
3. 专业编辑：正文改一个音和印刷标题→详情→专业页撤销/重做→浏览器返回；格式、原图、实际谱面与播放源一致，库名和印刷标题可不同。继续核对 [完整功能表](dolce-editor-parity.md)。
4. 调式：保持音高重记和实际移调分别应用→看谱/试听→还原；人工改稿后旧还原禁用；不支持的多声部或有损跨格式不替换原稿。纸张/字号不因转换偷偷重置。
5. 保存：保存入库成功回练习且不自动播放→重开同 id 内容/原图/版面一致；取消/失败/409 留稿，保存中再编辑不被清 dirty，恢复稿标明真实身份。
6. 阅读：同曲目字号/歌词和位置可保留，打印设置不跟着阅读改变；播放/暂停/回开头/拖进度/速度/循环连接真实播放器；进编辑或换曲停止。四种阅读/打印歌词组合实际下载对照。
7. 管理：两态 … 仅重命名/删除；未保存改稿时只改库名不写正文；同名 id 不串。删除取消不变，确认且服务端成功后列表/计数/返回一致；409/404/断网不伪装成功，返回不复活已删记录。
8. 查谱：未提交无示例；Enter/搜索一致；查询中文作者；列表、选中详情、实际声部/范围/来源许可清楚。旧搜索/旧准备响应不串；准备失败保稿；采纳取消留搜索和当前稿。
9. 导出：单页/多页 PDF、PNG ZIP、连续长图、PPTX、可重导入文本及完整识别项目；纸张、歌词、页码、来源、图形与音乐语义一致，既有全局升降号及页脚三开关保留。
