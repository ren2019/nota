# Nota 完整 Dolce 编辑页对照

> 本轮已补齐完整 Dolce 专业功能组的真实 App 浏览器操作与输出证据，并修复记号面板和右键菜单的内联编辑焦点缺陷。使用隔离 Chromium 和临时曲谱库，未写入生产数据。真实手机系统行为仍由 [#19](https://github.com/ren2019/nota/issues/19) 跟踪。

规格 [#9](https://github.com/ren2019/nota/issues/9)，实施 [#11](https://github.com/ren2019/nota/issues/11)。固定上游为 Dolce 0.8.3 / `2aab8ef2333ba9e1a2a7b342080381fcacdd41ac`；对照同时包含 Nota main `776498b` 已有的全局简谱输出及两行页脚，不用上游旧输出覆盖这些新增能力。

独立专业页沿用原来的 App、CodeMirror、OMR、播放器、记号面板、四种视图与整套 DOM。原工具栏和原 CSS 的 680/900 断点保留；手机依旧使用原「源码 / 预览」切换。详情底部「编辑」进入专业页，新增身份条的「返回曲谱详情」回到同首编辑态，切页不重新导入、不销毁编辑器/撤销历史、不复制一份正文。新增 Nota 调式不进入原记号板；调式使用详情的专属入口。

## 验证与边界

自动回归：`npm test`（真实 123/ABC/JP-Word/文本谱、混排 painter、MIDI/源位置、项目序列化/临时曲库、播放控制回归）及 `npm run build`。测试不使用 FakeApp 或模拟曲谱来宣称原编辑器通过。

### 本轮发现并修复的缺陷

原记号面板与右键菜单在启动内联输入后，无条件调用 `refocus()` 把焦点抢回谱面，输入框随即 blur 并关闭；用户无法填写调号、拍号、速度、和弦、歌词、文字或力度。先通过真实面板点击后填写输入框得到失败，再在 `MenuRunner.refocus` 增加活跃内联编辑保护。相同操作复跑通过，包含面板六种输入、歌词与右键和弦入口；无内联输入的动作仍恢复谱面焦点，后续快捷键和撤销检查也通过。

### 验收结论与限制

完整专业功能组已取得真实浏览器操作及输出证据，#11 不再因“仅核对 DOM 或代表性操作”留下同一整组待验。源码对照仍以固定 Dolce 0.8.3 和 Nota 原有功能为基线，没有替换专业工具集、删除格式能力或增加手机专用专业面板。

本轮不是所有格式、每一记号、每种谱例和每个屏宽的笛卡尔积穷举；复杂音乐正确性继续服从各格式原支持条件及既有引擎回归。没有实测 Tauri 原生功能，也不以 Web 结果代替 iPhone/Android 的软键盘、音频、后台、文件挑选/下载/分享和系统打印；这些真实手机系统项保留在 #19。识别质量及五线谱识别准确率不在本次 IA 功能保留验收中被重新承诺。
