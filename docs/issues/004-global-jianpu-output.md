# NOTA-004：全局简谱输出设置与升降号显示模式

状态：规格已发布，待实施。用户已确认本规格的测试入口与验收范围。后续以 [GitHub issue #1](https://github.com/ren2019/nota/issues/1) 为准；本文件保留发布时的规格快照。

分诊标签：`ready-for-agent`（已应用于 GitHub issue）。

## Problem Statement

陪孩子练琴时，用户需要每个变音都能直接读懂，也需要在谱面较密时选择省略重复记号。《莫斯科郊外的晚上》保持音高重记到 `1=C` 后，曾显示 `1 ♭3 5 3`；第四音实际仍是 E♭，但同小节记号延续的写法容易让读谱者误以为是 E 本位。

当前补丁已让保持音高重记逐音输出变音记号，但规则固定在转换功能内，用户无法选择，也不能保证打开已有曲谱、切换视图与各导出入口都采用同一偏好。数字大小、纸张和页脚等设置已有能力，应复用并让其关系清楚，避免增加多套配置。

## Solution

在现有「设置」中增加「简谱输出」，提供当前设备上所有曲谱共用的升降号显示模式：

| 模式 | 同一小节示例 | 规则 |
| --- | --- | --- |
| 逐音明确标注（默认） | `1 ♭3 5 ♭3` | 每个偏离当前 `1=` 基准的音明确标出升降号。 |
| 小节内延续 | `1 ♭3 5 3` | 依既有简谱语义省略同小节可沿用的重复记号。 |

两种模式都保留保证实际音高正确所必需的还原号。切换后立即更新简谱预览，后续简谱图形导出与可用的 123 文本输出采用相同偏好。切换设置本身不改写编辑源码、不触发入库，也不影响试听。

复用现有数字大小、纸张、方向、页边距、分页与展开模式、字体配色及页脚能力；页脚三个开关在新设置中可访问，已有快捷入口打开同一配置。此次不建设新的排版系统，也不新增歌词开关等其他功能。

## User Stories

1. 作为陪孩子练琴的家长，我希望在现有设置中找到「简谱输出」，以便集中调整读谱与打印偏好。
2. 作为初学者，我希望默认逐音显示需要的升降号，以便不用回看前面的记号就能辨认变音。
3. 作为熟悉简谱的用户，我希望选择「小节内延续」，以便减少重复符号、获得更简洁的谱面。
4. 作为用户，我希望在选择时看到两种模式的短例子，以便理解区别。
5. 作为用户，我希望切换模式后当前简谱立即更新，以便在导出前检查结果。
6. 作为用户，我希望从曲库重新打开的已有曲谱也采用全局设置，以便不必先重新转换才能应用偏好。
7. 作为用户，我希望新建、图片识谱和数字谱导入后可显示的简谱采用同一偏好，以便不同来源的曲谱读法一致。
8. 作为用户，我希望原样、展开和已有混排视图中的简谱部分采用同一模式，以便切换视图不改变读谱规则。
9. 作为用户，我希望实际移调与保持音高重记的结果都遵循该设置，以便输出风格一致。
10. 作为用户，我希望重复升号和重复降号都受该设置控制，以便相同规则覆盖所有变音。
11. 作为用户，我希望必要的还原号在两种模式下都正确保留，以免后续本位音继续被升降。
12. 作为用户，我希望跨八度、跨小节和曲中更换基准时记号仍正确，以免显示设置改变旋律或音区。
13. 作为用户，我希望切换设置时试听的每个音保持一致，以便放心选择自己易读的写法。
14. 作为用户，我希望节奏、休止符、歌词、倚音、连线、小节和反复结构保持，以便只调整记号呈现。
15. 作为用户，我希望简谱 PDF 与预览使用相同记号规则，以便打印后可以直接练习。
16. 作为用户，我希望简谱 PNG 的每一页都采用相同规则，以便分享图片时保持一致。
17. 作为用户，我希望现有可用的 PPTX 简谱输出采用同一规则，以便投影练习与打印读法一致。
18. 作为用户，我希望导出的 123 文本使用所选记号形式且重新导入后音高不变，以便继续编辑或分享。
19. 作为用户，我希望仅切换输出设置不会修改编辑源码或曲库原稿，以便保留自己的版本和校对成果。
20. 作为用户，我希望明确执行转换、保存或文本导出时才生成相应结果，以便控制内容修改。
21. 作为用户，我希望关闭重开浏览器或 PWA 后仍记住模式与练习谱数字大小，以便不必重复设置。
22. 作为家庭成员，我希望该偏好只影响当前设备，以便不打扰家人设备上的选择。
23. 作为已有用户，我希望升级后保留原有字号、纸张、样式与页脚设置，以免必须重新配置。
24. 作为用户，我希望设置存储不可用或损坏时仍能按默认值正常预览与导出，以便基本工作流不中断。
25. 作为用户，我希望从「简谱输出」或原有页脚快捷入口调整同一组署名、日期和页码开关，以便避免互相矛盾的设置。
26. 作为用户，我希望五线谱记号规则和 MIDI 实际声音保持原有行为，以便简谱输出偏好不会意外改变其他内容。
27. 作为用户，我希望已知有损的数字谱转换仍被拦截，以免为应用显示偏好而破坏原谱。

## Implementation Decisions

- 在现有设置对话框内增加「简谱输出」，使用两项单选及短例子；不新增顶层页面或复杂设置导航。
- 定义一个集中管理的简谱升降号输出策略，两种模式为逐音明确标注与小节内延续，默认采用前者。预览、转换与导出读取同一配置，不各自维护默认值或重复规则。
- 沿用当前本地设置持久化机制；新增字段需校验，缺省、非法值或读取失败均回退到逐音明确标注。全局指当前浏览器或 PWA 存储范围内的所有曲谱，不代表家庭服务器同步或独立容器共享设置。
- 升级时仅补充缺失字段，保留现有字号、主题、纸张、页脚等设置。练习谱数字大小记住最后一次明确选择；不强制重置现有用户字号。
- 页脚三个开关接入现有配置的同一读写入口；迁移如有需要必须保留已存选择，避免建立第二组页脚状态。
- 在输出派生阶段，先按原简谱语义解析逐音实际音高，再按所选策略生成输出记号。不能直接按字符增删重复升降号；也不能让输出显示策略影响输入的记号延续规则。
- 沿用当前有效简谱表示，临时计算音高用于投影与验证，不另建持久化绝对音高模型。复用原排版投影，保留元素标识及原文定位，使选择、可视化编辑与播放高亮仍对应原稿。
- 两种模式都按当前基准及真实小节边界处理，遵循已有跨行续小节规则，并正确处理基准变化、八度及必要还原号。不能因视觉换行错误重置记号，也不能跨真实小节沿用已失效的记号。
- 两种显示模式均不得改变逐音音高、音区、节奏或结构。原样、展开及现有混排中的简谱层共用策略，纯五线谱继续使用其既有规则。
- 现有可用的简谱 PDF、PNG、多页 PNG 包与 PPTX 路径消费同一派生结果；设置变化使旧预览与导出缓存失效。输出时采用同一配置快照，避免多页生成过程中混用模式。
- 导出 123 文本采用所选形式，并验证重读后语义等价；不借此增加其他格式转换能力。对于原来不能无损转为 123 的来源，仍保留原格式并报告限制。
- 明确执行实际移调或保持音高重记时，生成结果采用当前配置；不再在保持音高重记内部固定逐音模式。仅切换设置时不调用源码替换或曲库保存，不改变项目原始文件、识谱证据或来源验证状态。
- 试听与 MIDI 保持原来的真实音高和结构；MusicXML、原始项目保存等继续保留音乐数据，不因简谱显示偏好被重写为另一种记谱规则。
- 纸张、方向、边距、原样与展开、字体配色等复用原入口与行为；本轮不重新整理全部样式设置，不让练习谱快捷导出意外覆盖用户已选的升降号模式。
- 不增加账户、数据库、服务器配置 API、大型依赖或无关重构。

## Testing Decisions

- 用户已确认：沿用现有转换链路验证音高与结构不变，并在浏览器核对设置切换、预览和 PDF、PNG、PPTX、123 输出一致性。
- 优先以「输入曲谱 + 输出设置 → 可检查的输出及可重读的音乐语义」作为一个共享的高层回归入口，复用现有转换、文本重读、排版投影和统一播放入口；避免分别测试内部记号计算步骤。设置持久化仅补少量对外行为检查。
- 好的测试应证明用户看到什么、导出什么、播放什么，以及原稿是否被改动。不要断言私有方法、缓存实现、函数调用次数或复刻实现公式。
- 使用两音重复变音最小用例和《莫斯科郊外的晚上》真实库中原稿：逐音模式首小节显示 `1 ♭3 5 ♭3`；延续模式显示 `1 ♭3 5 3`；两者前四音实际音高均为 C4、E♭4、G4、E♭4，且完整逐音音高一致。真实文件保留在本地测试材料区。
- 借鉴现有全部调号组合与两种转换的回归。覆盖重复升降号、变音后还原、跨八度、真实小节边界、跨行续小节、曲中更换基准、倚音及延音连线，逐音比较实际音高和音区；节奏、休止符、歌词、小节与反复结构保持。
- 将同一组样谱经过两种模式再切回，验证无累积变化、无重复叠加记号、输入文档不变；已明确保存的作品不因更改全局偏好被自动更新。
- 验证转换写出、文本重读、实际排版投影和播放输入都达到预期，避免只有文本补了降号、排版或发声仍不一致。
- 在浏览器或独立 PWA 完成真实操作：切换模式、重开设置、重开曲谱、刷新或重启，检查当前及其他曲谱采用相同偏好，现有数字大小与页脚选择保留；存储损坏或不可用时能正常回退。
- 目视核对单页、多页以及连续图的现有可用导出，PDF、PNG、PPTX 中的简谱遵循同一模式；较长记号文本不得重叠、裁切或产生非预期空白页。新增记号占宽导致合理重排是允许的，不要求两种模式分页完全相同。
- 检查原样、展开和现有混排简谱层；纯五线谱、MIDI、MusicXML 与保存原项目不受显示切换影响，现有有损转换保护仍生效。
- 以现有页脚组合、时区、多页及转换测试为先例，运行相关回归与生产构建。实际导出验收必须包括下载和目视检查，不以内部投影通过冒充浏览器成品通过。

## Out of Scope

- 新增歌词显示开关、独立歌词字号控件、音符间距或行距的简化控件。
- 全面重做现有设置面板、样式系统、纸张体系，或引入模板／预设管理系统。
- 改变识谱准确性、实际移调算法、音高拼写偏好或提供新的声部提取能力。
- 新增独立 SVG 导出，新增原来不支持的格式或绕过有损转换保护。
- 账户、用户系统、跨设备偏好同步、家庭服务器全局策略及单曲覆盖设置。
- 自动批量改写历史曲谱、修改原图校对稿或重新标记来源验证通过。
- 改变五线谱记号显示约定，或影响 MIDI、试听的实际声音。

## Further Notes

本规格承接 NOTA-003。此前的逐音降号补丁已部署，但其行为仅固定在保持音高重记入口；本任务是把这一能力提升为全局输出策略，而不是再次改变音乐语义。原先第四音无显式降号时，实际音高也仍为 E♭。

已有其他输出控制项盘点：

| 项目 | 当前能力 | 本任务处理 |
| --- | --- | --- |
| 升降号方式 | 保持音高重记固定逐音标注 | 新增两种全局模式，贯通显示与输出。 |
| 数字大小 | 标准、大字、特大及现有样式字号 | 复用，持久化练习谱的明确选择。 |
| 纸张、方向、页边距 | 已有设置 | 复用原入口。 |
| 分页与连续长图 | 底座已有 | 保留行为并纳入一致性检查。 |
| 原样与展开 | 已有视图模式 | 保留行为，分别应用相同记号策略。 |
| 字体与配色 | 已有样式设置 | 复用，不新增重复配置。 |
| 品牌、日期、页码 | 已有三个页脚开关 | 新入口与原快捷入口共用原配置。 |
| 歌词显示 | 尚无统一开关 | 后续独立小改动。 |
| 音符间距、行距、歌词字号 | 排版层有相关能力，入口不完全统一 | 留待后续，不扩展本轮范围。 |

项目已配置 GitHub Issues 作为 tracker。后续需求澄清、实施进度和验收结果统一记录在对应 GitHub issue；历史本地文档仅作规格与验证证据参考。
