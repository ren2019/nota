# NOTA-003：保持音高重记中的重复升降号

状态：修复已部署，自动验证通过；浏览器目视复验受电脑工具启动失败阻断。

## 复现与最小输入

库中《莫斯科郊外的晚上》，选择保持音高重记到 `1=C`。原第一小节 `6,_ 1_ 3_ 1_`，原基准 `1=E♭`。旧输出为 `1_ b3_ 5_ 3_`，第四音无显式降号。

临时原曲复现命令 `node local/qa/renotation-bug.mjs` 实际失败：`fourth note must visibly show flat-3`，actual `undefined`，expected `flat`。最小输入为 `K:1=bE` 后接 `1 1`，旧输出 `b3 3`，相同失败。两个音和非 C 基准都是触发重复降号省略所必需的；移除拍号、时值及终止线仍复现。

临时脚本完成后已移除，持久回归命令为 `node app/scripts/nota-check.mjs`。在修复前新增断言实际报错：`Actual: ["flat",null]`、`Expected: ["flat","flat"]`。

## 原因与修复

按顺序核查转换器的记号延续、写出丢失、渲染丢失三个假设。独立运行实际转换入口，第四音转换前后 MIDI 均为 63，41 个记谱音的实际音高全部保持；重复记号在转换器调用 `AccidentalCarry.mark` 时已经被省略。因此属于练习谱显示歧义，不是第四音被变成 E 本位。

仅改变输出记号策略后，重复降号出现。产品修复仅作用于 Nota 保持音高重记：每个偏离目标基准的音明确标升降号；仍更新原有延续状态，为随后的本位音输出必要还原号。未修改全局简谱解析、播放、导出和原库曲谱。
