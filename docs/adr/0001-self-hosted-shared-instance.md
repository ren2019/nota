# 自行部署的单实例共享曲谱库

2026-10-16，用户确认 Nota 面向多种制谱与练习场景，采用自行部署、同一实例共享曲谱库的产品形态，不建设登录、成员角色、多空间或跨实例同步。相比托管账户体系，使用者自行决定部署和访问范围，产品保持简单；能访问实例的人共用其曲谱库，保留并发更新的冲突保护。产品文案不指定使用者之间的关系。

采用完整服务的自行部署模式，取消 GitHub Pages 版；部署者可以配置自己的 HTTPS 反代。继续使用服务端持久化，不为静态站点增加浏览器曲谱库或第二套产品模式。具体域名、云厂商、网络拓扑和实例运行记录不属于公开架构决定，仅保存在被忽略的 `local/`。
