# 需求与边界

> 当前交付已包含 B 双态详情、完整 Dolce 独立编辑页、中文联网查谱与 iPhone 主屏幕 App。下文保留初始需求及追加范围的演变；当前使用见[根 README](../README.md)，发布与待验边界见[当前验收](acceptance/current-release.md)。Nota 不建设账号系统，部署者可另接入口登录网关。

## 使用场景

用户拿到歌曲的五线谱或简谱，希望转换、校对、练习并打印成易读的单旋律简谱。产品面向多种制谱与练习场景，文案不限定使用者关系。输入可能是照片、截图、扫描 PDF 或已有数字乐谱。歌词可选，优先保证音符、节奏与乐曲结构正确。

来源：[原对话](https://example.invalid/removed-private-discussion)。用户随后明确要求先做可运行的 MVP prototype，并在 Dolce 界面基础上增加功能；当前以这一指令为准。

## 已确认的要求

1. 支持五线谱转简谱，也能处理已有简谱；识别结果可人工校对。
2. 同时支持实际移调与保持音高的重新记谱，允许选择目标调或记谱基准，C 是常用目标。
3. 正确保留数字音符、休止符、升降号、高低八度、时值、附点、小节、连线与反复结构。
4. 输出干净、字迹清晰的可打印图片和 A4 PDF，歌词作为可选内容。
5. 内部只需要一套行之有效的简谱记录，不为了转换增加复杂模型或多个处理服务。

## 转换的准确含义

### 实际移调

首调简谱的基准从 `1=Eb` 改为 `1=C`，音级、相对八度、升降号与节奏保持，实际声音随基准改变。音程、旋律性质和节奏关系应保持。

### 重新记谱

实际声音保持原样，换用 `1=C` 作为数字参照。每个音需要重算数字、升降号和八度点；单改标题不能完成这一操作。

一个明确八度的合成验收例子，约定 `1=C` 的无点 `1` 是 C4，`1=Eb` 的无点 `1` 是 Eb4：

| 版本 | 音符（数字 / 八度） | 实际音高 |
| --- | --- | --- |
| 原谱，`1=Eb` | `6 / -1`、`1 / 0`、`3 / 0` | C4、Eb4、G4 |
| 实际移调到 `1=C` | `6 / -1`、`1 / 0`、`3 / 0` | A3、C4、E4 |
| 保持音高，改用 `1=C` 记谱 | `1 / 0`、`b3 / 0`、`5 / 0` | C4、Eb4、G4 |

此表是验证用例，不是原图的逐音转写。选定底座后应把其实际八度约定记录清楚，并覆盖跨八度及升降号的边界。具体落在哪个八度，不能只靠不带八度点的 `6 1 3` 示例确定。

## 最小工作流

导入曲谱 → 对照原谱校对 → 选择转换方式和目标 → 排版并导出。

先复用一个已有项目的识谱、编辑和排版能力，补齐转换及打印工作流。优先验证专用识谱能力；是否增加模型辅助，由实际样谱表现决定。

## 当前阶段的边界

当前交付为基于 Dolce 的可运行 Web MVP，复用其 TypeScript/Vite 应用、123 简谱记录、编辑与排版引擎，增加两种转换与 A4 PNG/PDF 输出。转换先覆盖单首、单声部、单旋律。

自动找谱、在线账号、云端同步、批处理、左右手双行、指法生成及自动展开反复均不属于当前最小闭环；需要时再单独确定优先级。

用户追加要求：Nota 品牌与 Logo、底部 Dolce 署名、共享曲谱库与搜索；支持自行部署。曲谱采用主机文件持久化，访问同一实例的人共享。

2026-10-16 最新确认：开源发布采用 MIT；以自行部署的单实例产品为方向，不建设登录、成员角色或多空间。界面统一称“曲谱库”，共享范围表述为“曲谱保存在当前实例，访问同一实例的人共享”。支持部署者使用自己的域名与 HTTPS 反代；取消 GitHub Pages 版，不增加浏览器本地曲谱库或静态版分支。具体实例的部署配置与运行状态只保存在被忽略的 `local/`，不进入公开规格。架构决定见 [ADR](adr/0001-self-hosted-shared-instance.md)。

## 第一阶段验收

- 基于用户指定的 Dolce 底座运行现有界面，实际接通新增功能。
- 用人工校对过的同一份样谱生成两种 `1=C` 版本：实际移调版与音高保持的重新记谱版。
- 两种输出均能核对每个音的八度、节奏和结构；PNG 清晰，A4 PDF 无裁切和符号丢失。
- 保留可编辑稿，单个错误可以局部修正；识别未确认的内容有明确标记。

已取得 AirDrop 的 `IMG_4548.JPG` 和 `IMG_4549.PNG`，作为真实识谱测试用例；验收范围与新增品牌、页脚和 Safari App 用户故事见 [user-stories.md](user-stories.md)。自动识别和人工校正分开验收。
