# Nota MVP 用户故事

> 本文保留早期 MVP 用户故事。当前 IA 规格以 [GitHub #9](https://github.com/ren2019/nota/issues/9) 为准，最新交付结果见[当前发布与验收](acceptance/current-release.md)。

采用自行部署的单实例曲谱工作流；不新增登录、成员角色、多空间或跨实例同步。当前完整 IA 与旅程规格以 [GitHub #9](https://github.com/ren2019/nota/issues/9) 为准，受控的联网找谱以已接入范围为准。

| 用户故事 | 最小验收标准 |
| --- | --- |
| 作为用户，我能浏览、搜索已入库的音乐并查看谱子。 | 首页创作区下方列出曲名、调号与拍号；按曲名/调号搜索，打开后显示谱面。 |
| 作为用户，我能上传乐谱图片，识别并完成编辑。 | 支持 JPG/PNG；识别后可对照原图，修改音符、八度、节奏、歌词及反复结构。识别结果未经核对不等同于正确。 |
| 作为用户，我能保存作品，下次或换设备继续。 | 保存到当前实例的共享曲谱库；重新打开保留当前谱文、原图与版式；其他人同时更新时不静默覆盖。 |
| 作为练习者，我能实际移调，或保持声音重新记谱。 | 两种操作明确区分；逐音验证音高/音区及节奏、连线和反复结构。 |
| 作为用户，我能下载清晰的打印版。 | 单页/多页 A4 PDF、PNG 可下载；正文不裁切；统一页脚 `Typeset with Nota · YYYY-MM-DD`，多页右下角显示 `当前页 / 总页数`。日期取导出设备的本地时区。三个页脚开关默认开启。 |
| 作为用户，我能从局域网打开 Nota，也能保存成 Safari App。 | LAN 地址正常打开；首页展示 Nota 与准确 Slogan `A simple way to make sheet music.`；Safari 添加到程序坞后可独立启动并访问同一曲谱库。 |

## 真实图片验收

用户 AirDrop 的 `IMG_4548.JPG`（《星条旗》，仅所提供的第一页）和 `IMG_4549.PNG`（《莫斯科郊外的晚上》）作为真实用例。原图、初次识别稿、独立人工转写、差异记录及导出件保存在忽略目录 `local/test-cases/`，不提交原曲图片。

准确性必须对照可见原谱，覆盖音符、升降号、八度、时值/附点、休止符、小节、连线与反复。分别记录自动识别结果和人工校正结果，不用校正稿冒充自动识别通过。

验收证据见 [acceptance.md](acceptance.md)。
